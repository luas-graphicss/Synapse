Primeiros passos

Do primeiro carregamento até um projeto rodando no preview. Se você quer apenas testar a IDE, os dois primeiros blocos bastam.

revisado em 09/09/2026 leitura 8 min público: iniciante

Antes de começar

A IDE roda em navegadores baseados em Chromium e no Firefox recente. Ela depende de armazenamento local do site, de módulos ES e de Web Workers.

  • Evite janela anônima: o navegador descarta o projeto ao fechar a aba.
  • Se você usa bloqueadores agressivos, libere a origem da IDE. Alguns bloqueiam o iframe do preview.
  • Para terminal, instalação de pacotes e dev server, deixe o relay rodando na sua máquina. Detalhes em Terminal e relay.

Criar um projeto do zero

  1. Abra a IDE. Na primeira visita aparece a tela de boas-vindas com as ações principais.
  2. Escolha começar um projeto vazio. A IDE cria a estrutura mínima de arquivos.
  3. No explorador, use o botão de adicionar para criar index.html, styles.css e app.js.
  4. Escreva algo no HTML e observe o preview. Ele reage a cada gravação, sem precisar apertar nada.

Se o preview não reagir, force a atualização com Mod+S e abra o console com Mod+`.

Importar um projeto existente

O botão Importar aceita três caminhos:

Origem Quando usar Observação
Arquivo .zip Projeto vindo de outro computador ou de um download. A IDE ignora pastas de dependência e artefatos de build.
Pasta local Você quer trabalhar em algo que já está no disco. Depende de permissão do navegador para ler diretório.
Arrastar e soltar Poucos arquivos soltos ou um zip único. Solte na área do editor, o overlay de importação aparece.
Cuidado

Importar substitui o conteúdo do projeto atual. Se houver trabalho não exportado, tire um snapshot antes. Veja Arquivos e persistência.

Entendendo o primeiro preview

O preview procura um ponto de entrada HTML na raiz do projeto. Se existir mais de um, ele prioriza index.html. Os caminhos dentro do HTML são resolvidos contra a raiz, então prefira caminhos relativos simples. 

index.html
styles.css
app.js
assets/logo.png

Para projetos com build real, como Vite ou React, o caminho é outro: instale as dependências pelo terminal e suba o dev server. O preview passa a mostrar o servidor de verdade, com recarga automática.

Guardar o trabalho

Não existe botão de salvar manual para cada arquivo. A gravação acontece quando você para de digitar e também ao trocar de arquivo. O que você deve fazer de tempo em tempo é exportar.

  • Exportar zip: cópia completa do projeto para guardar fora do navegador.
  • Snapshot: ponto de restauração dentro da própria IDE, bom antes de refatorar.
  • Histórico por arquivo: volta uma gravação específica sem mexer no resto.

Próximos passos sugeridos

  • Aprenda a janela por partes em Área de trabalho.
  • Deixe o editor do seu jeito em Configurações e atalhos.
  • Se algo travou logo no começo, vá direto para Solução de problemas.

Encontrou um passo que não funciona como descrito? Reporte pelo botão Ajuda na IDE.
