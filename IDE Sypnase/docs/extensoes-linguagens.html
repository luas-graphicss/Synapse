Extensões / Suporte a linguagens

Adicionando uma linguagem à IDE

Do realce de sintaxe declarativo até completions, hover, símbolos e diagnósticos programáticos. Tudo que uma extensão de linguagem faz, na ordem em que você vai precisar.

revisado em 15/09/2026 leitura 11 min público: dev

Camadas de suporte

Você não precisa entregar tudo de uma vez. Cada camada funciona sozinha e a próxima só adiciona por cima:

  1. Registro da linguagem (manifesto): extensões de arquivo, aliases, comentários e pares. Já libera detecção e comentar/descomentar.
  2. Gramática (JSON): realce de sintaxe. Sem código.
  3. Snippets (JSON): trechos por prefixo. Sem código.
  4. Providers (código): completion, hover, definição, símbolos, formatação, ações de código.
  5. Diagnósticos (código): sublinhados e painel de problemas.

1. Registrar a linguagem

"contributes": {
	"languages": [{
		"id": "zig",
		"extensions": [".zig", ".zon"],
		"aliases": ["Zig"],
		"filenames": ["build.zig"],
		"configuration": "language-configuration.json"
	}]
},
"activationEvents": ["onLanguage:zig"]

language-configuration.json descreve o comportamento do editor:

{
	"comments": { "lineComment": "//", "blockComment": ["/*", "*/"] },
	"brackets": [["{", "}"], ["[", "]"], ["(", ")"]],
	"autoClosingPairs": [
		{ "open": "{", "close": "}" },
		{ "open": "\"", "close": "\"", "notIn": ["string"] }
	],
	"wordPattern": "[A-Za-z_][A-Za-z0-9_]*",
	"indentationRules": { "increaseIndentPattern": "\\{\\s*$", "decreaseIndentPattern": "^\\s*\\}" }
}

2. Gramática

A IDE usa um formato de gramática próprio, mais simples que TextMate: uma lista linear de padrões com regex JavaScript e nomes de escopo. Cada linha é analisada da esquerda para a direita; o primeiro padrão que casar em uma posição vence. 

{
	"lineComments": ["//"],
	"blockComments": [["/*", "*/"]],
	"quotes": ["\""],
	"keywords": "fn const var if else while return",
	"patterns": [
		{ "match": "@[A-Za-z_]\\w*", "name": "support.function.builtin" },
		{ "match": "\\b(?:i|u)(?:8|16|32|64)\\b", "name": "storage.type" },
		{ "match": "\\b(fn)\\s+([A-Za-z_]\\w*)", "captures": { "1": "keyword", "2": "entity.name.function" } },
		{ "match": "\\b\\d[\\d_]*\\b", "name": "constant.numeric" },
		{ "match": "[{}()\\[\\];,.]", "name": "punctuation" }
	]
}
lineComments, blockComments, quotes
Tratados pelo tokenizador antes dos padrões, com suporte a escape e strings multilinha (multilineStrings: true).
keywords
Atalho: lista separada por espaço que vira o escopo keyword sem você escrever a regex.
patterns[].name
Escopo aplicado ao match inteiro. Os temas mapeiam os escopos padrão: keyword, storage.type, entity.name.function, constant.numeric, string.*, comment, variable, support.function.builtin, punctuation.
patterns[].captures
Escopo por grupo de captura quando um único padrão cobre várias partes.
Desempenho Regex com lookbehind e quantificadores aninhados deixam a digitação lenta em arquivos grandes. A IDE aborta um padrão que passa de 50 ms por linha e avisa no console do Extension Development Host.

3. Snippets

"snippets": [{ "language": "zig", "path": "snippets/zig.json" }]

// snippets/zig.json
{
	"Função pública": {
		"prefix": "pubfn",
		"body": ["pub fn ${1:nome}(${2}) ${3:void} {", "\t$0", "}"],
		"description": "Declara uma função pública."
	}
}

Tabstops ($1, $2, $0), placeholders (${1:nome}) e escolhas (${1|a,b,c|}) seguem a sintaxe padrão. Para inserir por código use new synapse.SnippetString(...) em editor.insertSnippet ou em CompletionItem.insertText.

4. Providers

Registre em activate e adicione cada retorno a context.subscriptions. O seletor pode ser o id da linguagem ou um DocumentFilter com pattern. 

const { languages, CompletionItem, CompletionItemKind, Hover, MarkdownString, Location, Range, Position } = synapse;

languages.registerCompletionItemProvider('zig', {
	provideCompletionItems(document, position) {
		const linha = document.lineAt(position.line).text.slice(0, position.character);
		if (!/@\w*$/.test(linha)) return [];
		return BUILTINS.map((nome) => {
			const item = new CompletionItem('@' + nome, CompletionItemKind.Function);
			item.detail = 'builtin';
			return item;
		});
	},
}, '@');

languages.registerHoverProvider('zig', {
	provideHover(document, position) {
		const palavra = document.getText(document.getWordRangeAtPosition(position));
		const doc = DOCS[palavra];
		return doc ? new Hover(new MarkdownString(doc)) : null;
	},
});

languages.registerDocumentSymbolProvider('zig', {
	provideDocumentSymbols(document) { return extrairSimbolos(document); },
});

languages.registerDocumentFormattingEditProvider('zig', {
	provideDocumentFormattingEdits(document) {
		const todo = new Range(new Position(0, 0), document.lineAt(document.lineCount - 1).range.end);
		return [synapse.TextEdit.replace(todo, formatar(document.getText()))];
	},
});
ProviderQuando rodaRetorna
CompletionDigitação, caracteres gatilho, Ctrl+EspaçoCompletionItem[] ou CompletionList
HoverMouse parado sobre uma palavraHover
DefinitionF12, Ctrl+cliqueLocation | Location[]
DocumentSymbolPainel de estrutura, Ctrl+Shift+ODocumentSymbol[]

Todos recebem um CancellationToken; verifique token.isCancellationRequested em loops longos. Providers que demoram mais de 2 s são cancelados e o tempo aparece no Inspetor.

5. Diagnósticos

const colecao = synapse.languages.createDiagnosticCollection('zig');
context.subscriptions.push(colecao);

function analisar(document) {
	if (document.languageId !== 'zig') return;
	const problemas = [];
	for (let i = 0; i < document.lineCount; i++) {
		const linha = document.lineAt(i);
		const idx = linha.text.indexOf('var ');
		if (idx !== -1 && !linha.text.includes('=')) {
			const range = new synapse.Range(i, idx, i, idx + 3);
			const d = new synapse.Diagnostic(range, 'Variável declarada sem valor inicial.', synapse.DiagnosticSeverity.Warning);
			d.code = 'zig/var-sem-valor';
			d.source = 'zig';
			problemas.push(d);
		}
	}
	colecao.set(document.uri, problemas);
}

synapse.workspace.textDocuments.forEach(analisar);
synapse.workspace.onDidOpenTextDocument(analisar);
synapse.workspace.onDidChangeTextDocument((e) => analisar(e.document));
synapse.workspace.onDidCloseTextDocument((doc) => colecao.delete(doc.uri));

Diagnósticos aparecem sublinhados no editor, no painel de problemas e no contador da barra de status, agrupados pelo source. Combine com um CodeActionsProvider que leia context.diagnostics para oferecer correções.

Testando uma linguagem

Testes rodam no worker com acesso ao workspace, então dá para abrir um documento fictício e exercitar os providers de verdade: 

const { describe, it, expect } = synapse.test;

describe('zig completions', () => {
	it('sugere builtins após @', async () => {
		const doc = await synapse.workspace.openTextDocument({ language: 'zig', content: 'const x = @' });
		const lista = await synapse.commands.executeCommand('synapse.executeCompletionItemProvider', doc.uri, new synapse.Position(0, 11));
		expect(lista.items.map((i) => i.label)).toContain('@import');
	});
});
