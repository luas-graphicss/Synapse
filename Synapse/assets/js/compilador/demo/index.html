Auto-compiler — demonstração

Detector de projeto, runtime WASI e shell de preview, rodando de verdade.

1. Detector de projeto

Um arquivo por linha, no formato caminho :: conteúdo. O conteúdo é opcional, mas é o que permite detectar GUI.

2. Execução no shell de preview

Dois binários WASI reais, executados pelo wasi.js dentro do iframe.

O que esta demo não faz: não compila C ainda. Os binários acima já vêm prontos, montados byte a byte para provar o runtime. Compilar de verdade depende de preencher catalogo.js com as URLs do Clang — veja VERIFICAR.md.
